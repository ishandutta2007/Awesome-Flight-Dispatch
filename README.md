## 💡 Overview & Operational Scope

This repository provides an authoritative guide to **Flight Dispatch Tools**, **EFB platforms**, and **Aviation Trajectory Calculators**. Whether you are an airline operational control center (OCC), business aviation operator, pilot, aeronautical researcher, or software engineer building custom dispatch software, this list tracks the most reliable enterprise SaaS platforms and transparent open-source aviation projects.

### 🌟 Key Capabilities Tracked:
- 🗺️ **Operational Flight Planning (OFP)** & Global Route Optimization (ICAO / FAA compliance)
- 🌤️ **Aviation Weather Briefing** (METAR, TAF, SIGMET, Wind/Temp Aloft grids)
- ⚖️ **Aircraft Performance & Weight and Balance (W&B)** calculations
- 📡 **ADS-B & Mode-S Live Trajectory & Flight Tracking**
- 📂 **Aeronautical Data Processing** (AIRAC cycles, AIXM, OpenAIR, ARINC 424)

## 🔓 Open-Source GitHub Projects

Community-driven open-source projects for self-hosting flight planning tools, calculating optimal aircraft trajectories, parsing aeronautical data, and rendering moving maps.

*Sorted by GitHub Star count (descending):*

- 🗺️ **[OpenFlights](https://github.com/jpatokal/openflights)** <a href="https://github.com/jpatokal/openflights/stargazers"><img src="https://img.shields.io/github/stars/jpatokal/openflights?style=social&color=white" alt="OpenFlights Stars" /></a>  
  Website and dataset for storing flight information, rendering paths on a world map, calculating statistics, plus free airline, airport, and route data.

- 🛩️ **[Little Navmap](https://github.com/albar965/littlenavmap)** <a href="https://github.com/albar965/littlenavmap/stargazers"><img src="https://img.shields.io/github/stars/albar965/littlenavmap?style=social&color=white" alt="Little Navmap Stars" /></a>  
  Free open-source flight planner, moving map, airport search, and navigation tool with procedure support and multi-simulator export formats.

- 🛰️ **[AirTrail](https://github.com/johanohly/AirTrail)** <a href="https://github.com/johanohly/AirTrail/stargazers"><img src="https://img.shields.io/github/stars/johanohly/AirTrail?style=social&color=white" alt="AirTrail Stars" /></a>  
  Modern open-source personal flight tracking system with interactive maps, statistics, multi-user support, and import from multiple sources.

- 📡 **[aeris](https://github.com/kewonit/aeris)** <a href="https://github.com/kewonit/aeris/stargazers"><img src="https://img.shields.io/github/stars/kewonit/aeris?style=social&color=white" alt="aeris Stars" /></a>  
  Real-time 3D flight radar and flight tracking web app using ADS-B data, MapLibre GL, and OpenSky Network integration.

- 🌐 **[react-flight-tracker](https://github.com/xSNOWM4Nx/react-flight-tracker)** <a href="https://github.com/xSNOWM4Nx/react-flight-tracker/stargazers"><img src="https://img.shields.io/github/stars/xSNOWM4Nx/react-flight-tracker?style=social&color=white" alt="react-flight-tracker Stars" /></a>  
  Open-source real-time flight tracker built with React, TypeScript, Mapbox, and OpenSky Network API.

- ⚙️ **[OpenAP / openap](https://github.com/junzis/openap)** <a href="https://github.com/junzis/openap/stargazers"><img src="https://img.shields.io/github/stars/junzis/openap?style=social&color=white" alt="OpenAP Stars" /></a>  
  Open aircraft performance models and trajectory optimization toolkit for fuel-optimal, wind-optimal, and custom-cost flight trajectories.

- 🕹️ **[x-dispatch](https://github.com/lyestarzalt/x-dispatch)** <a href="https://github.com/lyestarzalt/x-dispatch/stargazers"><img src="https://img.shields.io/github/stars/lyestarzalt/x-dispatch?style=social&color=white" alt="x-dispatch Stars" /></a>  
  Desktop application for flight planning, airport info visualization, navigation data, and flight launching.

- 🌍 **[openAIP](https://github.com/openAIP)** <a href="https://github.com/openAIP/stargazers"><img src="https://img.shields.io/github/stars/openAIP?style=social&color=white" alt="openAIP Stars" /></a>  
  Crowd-sourced open aeronautical information platform providing airspace, airports, navaids, and related data with parsers and tools.

- 🌿 **[HyPlan](https://github.com/ryanpavlick/hyplan)** <a href="https://github.com/ryanpavlick/hyplan/stargazers"><img src="https://img.shields.io/github/stars/ryanpavlick/hyplan?style=social&color=white" alt="HyPlan Stars" /></a>  
  Open-source Python library for planning airborne remote sensing campaigns, including flight lines, performance, and logistics.

- 📍 **[openap-top / opentop](https://github.com/junzis/openap-top)** <a href="https://github.com/junzis/openap-top/stargazers"><img src="https://img.shields.io/github/stars/junzis/openap-top?style=social&color=white" alt="openap-top Stars" /></a>  
  Open trajectory optimization package for aircraft fuel burn and path planning.

- 🇨🇭 **[navplan.ch](https://github.com/opacopac/navplan)** <a href="https://github.com/opacopac/navplan/stargazers"><img src="https://img.shields.io/github/stars/opacopac/navplan?style=social&color=white" alt="navplan.ch Stars" /></a>  
  Open-source VFR flight planning web application integrating aeronautical data, weather, and maps (focused on Switzerland with extensible architecture).

- 🔬 **[tangram (open-aviation)](https://github.com/open-aviation/tangram)** <a href="https://github.com/open-aviation/tangram/stargazers"><img src="https://img.shields.io/github/stars/open-aviation/tangram?style=social&color=white" alt="tangram Stars" /></a>  
  Modular open platform for real-time multidisciplinary aviation research, data fusion (Mode-S, weather), and plugin-based tooling.

- 🧩 **[AeroPlan](https://github.com/Kiptoo-Deus/AeroPlan)** <a href="https://github.com/Kiptoo-Deus/AeroPlan/stargazers"><img src="https://img.shields.io/github/stars/Kiptoo-Deus/AeroPlan?style=social&color=white" alt="AeroPlan Stars" /></a>  
  C++/Qt flight planner using A* routing, real-time maps, weather, and export to MSFS, X-Plane, and other formats.

- 💻 **[flight-dispatch-center](https://github.com/anldrms/flight-dispatch-center)** <a href="https://github.com/anldrms/flight-dispatch-center/stargazers"><img src="https://img.shields.io/github/stars/anldrms/flight-dispatch-center?style=social&color=white" alt="flight-dispatch-center Stars" /></a>  
  Professional aviation flight planning system for simulators with real navigation data, live weather, and multi-format export.

## 🧰 Additional Aeronautical Data & Framework Options

- 🗺️ **[Open Flightmaps](https://www.openflightmaps.org/)**: High-quality open aeronautical charts and mapping data.
- 🛫 **[OurAirports](https://ourairports.com/)**: Free, community-maintained global airport database containing over 40,000 airports.
- 🛰️ **[OpenSky Network](https://opensky-network.org/)**: Non-profit ADS-B and Mode-S flight tracking database and REST/Python APIs.
- 🧭 **[VFR Flight Planner Libraries](https://github.com/topics/flightplan)**: Community route generators and waypoint calculation modules.
- ⛽ **QSimPlanner-style Tools**: Open-source fuel and performance calculators for operational simulation.

## ⚠️ Disclaimer & Operational Notice

- This directory is a **community-curated index** for informational and educational purposes.
- Flight dispatch and operational flight plans (OFP) for real-world aviation must strictly adhere to national and international civil aviation regulations (FAA, EASA, ICAO).
- Self-hosted or open-source solutions used in real operations require validated AIRAC data cycles, redundant infrastructure, and formal compliance auditing.
